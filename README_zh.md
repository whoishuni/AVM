# YC_VesselTracer: 2D 血管路徑追蹤工具

本應用程式是一個桌面工具，專為半自動化追蹤 2D 血管攝影影像序列中的路徑而設計。它的核心目標是幫助使用者在連續的影像中，精準地識別並描繪出如血管般的結構。

本工具最關鍵的特色是其「血管記憶」系統。傳統方法可能會將影像序列攤平為單一影像進行分析，但本軟體則是逐幀分析影像序列，藉此理解血管隨時間的生長與連接方式。這種方法能夠實現更精準的路徑尋找，尤其在血管交叉、重疊的複雜區域，能有效避免演算法跳轉至不相關的血管上。

## ✨ 功能亮點

- **影像序列載入**: 支援載入包含多張影像（如 JPG, PNG 等格式）的資料夾，並將其視為一個時間序列進行分析。
- **互動式路徑標記**: 只需在影像上點擊，即可定義您想追蹤的血管路徑的起點、中途點和終點。
- **創新的血管記憶尋路演算法**: 採用一種改良的 A* 尋路演算法，該演算法利用時間序列資訊來追蹤最可能的血管路徑，智慧地避開空間上重疊但時間上不連續的其他血管。
- **強大的雜訊抑制**:
    - **手動降噪**: 可互動式地繪製矩形區域，將影像中的特定雜訊排除在分析之外。
    - **自動過濾**: 自動識別並移除影像中與血管結構無關的大面積高亮區域（例如導管或骨骼）。
- **可調式影像平滑**: 在分析前，可以透過即時預覽介面，互動式地調整高斯平滑的強度，以達到最佳的血管顯現效果。
- **視覺化分析流程**: 提供逐步的視覺化功能，讓使用者能清楚看見從影像過濾、遮罩生成到最終路徑規劃的完整流程，深入了解結果是如何產生的。

## 🔬 技術細節深度解析

為了精準識別並追蹤血管路徑，本工具採用了一套複雜且多階段的處理流程。以下為核心技術的詳細說明，旨在幫助開發者深入理解其運作原理。

### 階段一：血管增強與遮罩生成

在進行路徑尋找之前，必須先將血管從複雜的背景中清晰地分割出來。此流程的目標是處理雜訊並強化管狀結構：

1.  **預處理 - 雜訊過濾**:
    *   首先，系統會利用形態學操作（Morphological Operations）來識別影像中非血管的大型高亮物體（例如手術中使用的導管或骨骼結構）。這些物體會被標記並從後續的分析中移除，確保它們不會干擾血管的提取。

2.  **血管濾波 - 結合多重濾波器**:
    *   此為血管增強的核心步驟。我們並非依賴單一濾波器，而是巧妙地結合了 `scikit-image` 函式庫中三種功能強大的濾波器，以應對不同形態的血管：
        *   **Frangi 濾波器**: 基於 Hessian 矩陣的特徵值分析，此濾波器對偵測不同尺寸的血管結構特別有效。
        *   **Sato 濾波器**: 同樣是基於 Hessian 矩陣的濾波器，對於線狀和管狀結構的偵測效果顯著。
        *   **Meijering 濾波器**: 此濾波器對雜訊較不敏感，能提供一個穩定且可靠的基礎血管響應。
    *   **響應結合**: 系統會計算上述三種濾波器的輸出，並在每個像素點上取其最大值。這種策略綜合了各濾波器的優點，產生一個極具魯棒性的「血管可能性」（Vesselness）圖，最大化地突顯出影像中的血管網路。

3.  **二值化與後處理**:
    *   將前一步產生的「血管可能性」圖進行閾值處理，轉換成黑白分明的二值遮罩（Binary Mask）。
    *   最後，執行一個客製化的**斷連彌合演算法**。此演算法會先對二值遮罩進行骨架化（Skeletonization）以找到血管的中心線，然後偵測骨架中的斷點，並在一定距離內智慧地將這些斷裂的片段重新連接起來，形成更完整的血管網路。

### 階段二：改良型 A* 尋路演算法

本工具的路徑尋找並非傳統的影像搜尋，而是採用了一種客製化的 A* 演算法，其核心在於一個獨特的**成本函數（Cost Function）**，用以在使用者定義的標記點之間，找到最「自然」的血管路徑。移動到相鄰像素的總成本，是由以下幾個因素加權計算而成：

1.  **路徑一致性圖 (Path Coherence Map)** - **預分析階段**:
    *   當使用者標記**第一個點**時，系統會在背景執行一次類似 Dijkstra 的搜尋。這次搜尋的成本主要基於**路徑的曲折程度**和**亮度的變化**，用以懲罰不平滑的路徑。
    *   搜尋完成後，得到的成本圖會被反轉，形成一張**路徑一致性圖**。在這張圖上，數值越高的區域代表從起點開始，路徑越平滑、越連續。這張圖在最終的 A* 搜尋中佔有最高的權重，強烈引導著路徑沿著最可能的主血管幹道前進。

2.  **時間成本 (Temporal Cost)**:
    *   一個像素點的成本與它首次出現的影像幀數成正比。這個機制鼓勵路徑停留在較早出現並持續存在的血管中，有效防止演算法「跳躍」到那些在較晚的影像幀中才出現的不相關血管上。

3.  **血管身份懲罰 (Vessel Identity Penalty)**:
    *   在分析過程中，應用程式會建立一張**血管身份圖 (Vessel Identity Map)**，為整個影像序列中每一個連續的血管片段分配一個獨一無二的 ID。
    *   A* 演算法在搜尋時，若從一個 ID 的像素跳到另一個不同 ID 的像素，將會產生極高的懲罰。這個機制幾乎是強制性地讓路徑保持在單一、連續的血管結構內，是實現「血管記憶」功能的關鍵。

4.  **局部轉彎懲罰 (Local Turn Penalty)**:
    *   除了上述的創新成本外，演算法仍然保留了傳統的轉彎懲罰。此懲罰基於路徑前進方向向量的餘弦相似度來計算，確保最終產生的路徑在局部上也是平滑流暢的。

這種多面向的成本計算方法，使得演算法在面對複雜的血管交叉點時，能夠做出智慧的決策，傾向於追蹤一個在時間上連貫的單一血管，而非僅僅選擇空間上的最短路徑。

## 🚀 設定與安裝

本應用程式使用 Python 開發，並依賴數個常見的科學計算與圖形介面函式庫。

### 環境需求

- Python 3.6+

### 依賴套件

所需的 Python 函式庫如下：
- `PyQt6`: 用於建構圖形使用者介面。
- `opencv-python`: 提供核心的影像處理功能。
- `numpy`: 用於高效的數值運算與影像陣列操作。
- `scikit-image`: 提供進階的影像濾波與形態學功能（例如 Frangi, Sato 濾波器與骨架化）。
- `plotly`: 用於產生互動式的 3D 視覺化圖表。
- `PyQt6-WebEngine`: `plotly` 在 PyQt 環境下顯示圖表所需的網頁引擎。

您可以使用 pip 一次性安裝所有依賴：

```bash
pip install PyQt6 opencv-python numpy scikit-image plotly PyQt6-WebEngine
```

## 📖 使用指南

1.  **執行應用程式**:
    在您的終端機中，執行 `main.py` 腳本：
    ```bash
    python main.py
    ```
    *應用程式啟動時會請您選擇語言。*

2.  **步驟一：載入影像**
    - 點擊 **"選擇圖片資料夾"** 按鈕。
    - 選擇存放您影像序列的資料夾。影像將被自動載入並排序。
    - 載入後，第一幀影像會顯示在主視窗。您可以使用 **滑桿** 或 **'A' (上一張) / 'D' (下一張) 按鍵** 來瀏覽不同幀的影像。

3.  **步驟二：標記路徑點**
    - 點擊 **"開始標記路徑"** 按鈕進入標記模式。
    - 在影像上點擊以放置標記點，定義您想追蹤的血管路徑。您至少需要定義一個起點和一個終點。
    - 您可以在不同的影像幀上進行標記。
    - 當您標記了至少兩個點後，點擊 **"確認標記點"**。此時，畫面會更新為您所選幀範圍的最大強度投影（MIP）視圖。

4.  **步驟三：設定與分析**
    - 確認標記點後，一組新的工具按鈕將會出現。
    - **(可選) 調整平滑度**: 點擊 **"調整平滑度"** 開啟一個即時預覽對話框。使用滑桿找到一個能讓血管清晰但又不失細節的最佳設定。
    - **(可選) 繪製雜訊區域**: 點擊 **"繪製雜訊區域"**。接著，在影像上點擊並拖曳，繪製一個紅色矩形框以排除任何您不希望演算法分析的區域。您可以新增多個雜訊區域。
    - **執行分析**: 當您準備好後，點擊 **"執行完整分析"**。

5.  **步驟四：檢視結果**
    - 分析過程中會顯示一個進度條。
    - 處理完成後，一個名為 **"處理步驟檢視器"** 的對話框將自動開啟。
    - 使用 **"下一步"** 和 **"上一步"** 按鈕，您可以檢視分析過程中的每一步，包括：
        - 影像過濾與遮罩生成的各個階段。
        - 彩色的 **血管身份圖**，它展示了「血管記憶」功能如何將血管片段分組。
        - 最終在血管遮罩上繪製的 A* 路徑。
        - 疊加在原始影像上的最終結果。
    - 您也可以點擊 **"顯示3D視圖"** 來從三維空間（X, Y, 時間）觀察血管結構與追蹤路徑。
    - 關閉步驟檢視器後，最終結果會顯示在主視窗中。

6.  **重置**
    - 若要開始一個新的分析，點擊 **"全部重置"** 按鈕。這將清除所有資料，並將應用程式恢復到初始狀態。
